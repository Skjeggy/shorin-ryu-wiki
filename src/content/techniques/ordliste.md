## Slag — Zuki og Uchi

**Zuki** = slag (enkelt) · **Tsuki** = slag (flertall)

| Teknikk | Forklaring |
|---|---|
| **Oi-zuki** | Forstegslag — slag med fremre hånd i samme retning som skrittet |
| **Gyaku-zuki** | Omvendt slag — slag med bakre hånd |
| **Maeken-zuki** | Slag med fremre hånd |
| **Seiken-zuki** | Rett slag med knyttneve |
| **Tateken-zuki** | Vertikalt slag (knyttnevens topp peker opp) |
| **Ura-zuki** | Kort oppoverslag; «kroket» slag |
| **Age-zuki** | Stigende slag |
| **Kagi-zuki** | Kroket slag / hook |
| **Mawashi-zuki** | Sirkulært slag / swingslag |
| **Morote-zuki** | Dobbelt slag med begge armer |
| **Yama-zuki** | Fjellslag — dobbelt slag i ulike høyder simultant |
| **Sokumen-zuki** | Sideslag |
| **Hiraken-zuki** | Slag med halvt lukket neve (fingerknokene) |
| **Ippon-ken-zuki** | Slag med ett fremstående knokeledd |
| **Nukite** | Spydfingerslag |
| **Empi / Hiji** | Albueslag |
| **Uraken-uchi** | Slag med baken av knyttnevs knokler |
| **Shuto-uchi** | Knivhåndsslag (med håndkanten) |
| **Haito-uchi** | Slag med tommelside-kanten av hånden |
| **Tetsui-uchi** | Hammerneveslag (med undersiden av knyttnevsen) |
| **Teisho-zuki** | Håndflateslag |

## Stillinger — Dachi

**Dachi** = stilling. Se også [Dachi — stillinger i Shorin-Ryu](../dachi/) for detaljer om de viktigste stillingene.

| Stilling | Forklaring |
|---|---|
| **Heisoku-dachi** | Føttene samlet, tærne peker frem |
| **Musubi-dachi** | Hælene samlet, tærne ut til siden |
| **Heiko-dachi** | Parallell stilling, skulderbredde |
| **Shizen-dachi / Shizentai-dachi** | Naturlig stilling |
| **Zenkutsu-dachi** | Forlent stilling — vekt fremover |
| **Kokutsu-dachi** | Tilbakelent stilling — vekt bakover |
| **Naifanchin-dachi** | Sidelengs stilling med innovervridde knær |
| **Kiba-dachi / Shiko-dachi** | Ridestilling |
| **Neko-ashi-dachi** | Kattestilling — vekt nesten helt på bakre ben |
| **Kosa-dachi** | Kryss-stilling |
| **Sanchin-dachi** | Timeglass-stilling med innovervridde føtter |
| **Uchi-hachiji-dachi** | Innovervendt V-stilling |
| **Sotohachinoji-dachi** | Utovervendt V-stilling |
| **Ippon-ashi-dachi / Sagi-dachi** | Stilling på ett ben |
| **Renoji-dachi** | L-formet stilling |
| **Moto-dachi** | Grunnstilling (halvt forlent) |
| **Gyaku-zenkutsu-dachi** | Omvendt forlent stilling |
